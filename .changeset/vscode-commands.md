The VS Code extension contributes three commands: **Vela: Restart Language Server**, which restarts the server and re-reads every `vela.config` without reloading the window, **Vela: Show Output**, and **Vela: Sort Classes**, which runs `source.sortVelaClasses` on the active TypeScript or TSX file.
